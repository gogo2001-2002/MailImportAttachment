# MailImportAttachment

IP-Symcon-9-Modul zum Abrufen neuer E-Mails per IMAP, Prüfen eines erlaubten Absenders, Speichern von Anhängen mit eindeutigen Dateinamen und anschließendem Aufruf eines konfigurierten IP-Symcon-Skripts.

Die eigentliche Modulentwicklung erfolgt im Branch `develop`. `main` dient als stabiler Stand und wird erst nach erfolgreichem Test und Freigabe aktualisiert.
